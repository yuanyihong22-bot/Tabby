# Tabby（桌面表格便签）

把表格数据贴成桌面小组件，点一下单元格即可复制内容。

## 使用

1. 启动：双击桌面的「Tabby」快捷方式（或 `dist/tabby.exe`；开发用 `uv run python -m src.main`）
2. 桌面上会出现一个便签窗口。
3. 在 Excel 复制表格后，点便签按 Ctrl+V（或右键 → 粘贴），新内容**追加到表格下面**。
4. 点单元格 → 选中并复制；按住拖动框选多格 → Ctrl+C 按结构复制。
5. 点左侧行号选中整行、点上方列标题选中整列 → 按 Delete 删除。
6. Ctrl+Z 撤销；Ctrl+滚轮（或 Ctrl+加/减号）缩放字号，Ctrl+0 恢复。
7. 顶部按钮：`置顶`（临时提到最前）、`＋`（新建便签）、`设置`（开机自启 / 创建桌面快捷方式）、`×`（关闭本便签）。
8. 拖动顶部灰色横条移动位置；右键 → 复制 / 粘贴 / 清空 / 新建便签 / 退出全部。

数据自动保存，重启后恢复；多个便签各自独立保存。

## 开发

```bash
uv sync          # 安装依赖（pytest）
uv run pytest    # 跑测试
```
