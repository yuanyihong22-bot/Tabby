# 桌面表格便签

把表格数据贴成桌面小组件，点一下单元格即可复制内容。

## 使用

1. 启动：`uv run python -m src.main`（或 `uv run python launcher.py`）
2. 桌面上会出现一个小便签窗口。
3. 在 Excel 复制表格后，点便签按 Ctrl+V（或右键 → 粘贴），新内容**追加到表格下面**。
4. 左键点任意单元格 → 复制该格；按住拖动框选多格 → Ctrl+C 按结构复制。
5. 点左侧行号选中整行、点上方列标题选中整列 → 按 Delete 键删除。
6. 拖动顶部灰色横条可移动位置；右键 → 退出。

数据自动保存，重启后恢复。

## 开发

```bash
uv sync          # 安装依赖（pytest）
uv run pytest    # 跑测试
```
